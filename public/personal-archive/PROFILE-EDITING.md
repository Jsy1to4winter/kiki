# 资料编辑与发布

音乐键旁的滑杆图标打开“编辑资料”。可修改姓名、年龄、技能、标签、拟化物、锚点、自我介绍、头像，以及三张痕迹卡片的名称和链接。

- “保存并查看”写入当前浏览器的 IndexedDB，刷新后保留；其他访客看不到本机草稿。
- “导出发布文件”下载 `site-profile.json`。头像上传后会随该文件内嵌导出，不必另找图片文件。
- 如需全站公开更新，将导出的文件替换仓库 `public/personal-archive/site-profile.json` 并提交；现有 Pages 工作流会发布。
- 本机草稿优先于已发布配置；要查看新的公共配置，可点击“恢复已发布版本”清除本机草稿，或使用未保存草稿的浏览器。
- “导入配置”先载入表单，点击保存后才应用。链接只允许 HTTP/HTTPS；留空时卡片不跳转。
- `trace-links.json` 保留为旧版链接配置后备；启用资料编辑后，以 `site-profile.json` 的 links 为准。

这是静态网站的本机编辑与导出流程，没有服务器写入或 GitHub 身份认证，不会在浏览器中自动提交仓库。
