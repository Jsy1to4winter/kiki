# 资料编辑与发布

当前已连接 Supabase。音乐键旁的滑杆图标打开登录弹窗；使用管理员邮箱和密码验证后可编辑。资料保存在云端，其他访客打开或刷新页面即可查看；图片上传同样需要管理员权限。

可修改个人资料、自我介绍标题与正文、头像、锚点、须知标题与正文、五个导航名称、评价页文案，以及三张痕迹卡片的名称和链接。须知用空行分段。链接只允许 HTTP/HTTPS，留空不启用跳转。

- “保存并查看”保存至 Supabase，成功后返回页面；失败时显示错误，不会假装同步成功。
- “导出资料备份”下载 site-profile.json。头像上传后随该文件内嵌导出。
- “导入配置”先载入表单，点击保存后才同步公开。
- “重新载入云端资料”丢弃表单里未保存的修改，重新读取云端内容。
- 首次连接且云端尚无资料时，管理员编辑页会载入此浏览器原有草稿，点击保存后才公开。原来的本机相册图片须重新上传。

私藏的三个相册和评价相册分别保存，均支持多张图片。前三张按上传顺序作为叠放封面；进入相册后可查看全部图片，再点击单张放大翻页。云端每张图片上限 20MB。

连接与权限说明见 SUPABASE-SETUP.md。SQL 位于项目根目录 supabase/migrations/202611020001_archive.sql。Publishable key 可公开；不要把管理员密码或 Secret key 放入仓库。

关闭 supabase-config.json 的 enabled 后，会切换为原本的本机编辑模式：保存写入当前浏览器的 IndexedDB，其他访客看不到；公开默认内容使用 site-profile.json。此本机模式不需要管理员登录，数据库本身仍由 Supabase 权限策略保护。
