移动鼠标或在手机上滑动，粒子会散开并弹性归位；左下角输入文字、按回车可更新内容（最多 20 字）。

## 后续让我集成的提示词

> 使用仓库 `tools/text-particleization/index.html` 中的 Da0Mine 文字粒子交互效果，把「@Jsy_1to4」放到网站的【指定位置】。保留鼠标和触摸靠近时粒子散开、离开后弹性聚拢及发光拖尾，粒子颜色改为 #08fff9，适配手机，并保持现有日志的布局与点击操作。

把【指定位置】换成首页标题、加载页等需要的位置。只需点名这个项目和位置，我即可读取本地源码进行整合。

## 实现提示

这是原生 Canvas 2D 效果，不是 Three.js 模型，也不是可安装的 Skill。源码通过离屏画布采样文字、排斥力、弹簧力和阻尼逐帧更新粒子。可调参数为 `REPEL_RADIUS`、`REPEL_FORCE`、`SPRING`、`FRICTION`。

整合时将全屏画布和 window 事件改为目标容器范围，处理与日志 Three.js 场景的指针事件冲突，提供卸载清理、页面隐藏暂停及减少动态模式。上游 README 声明 MIT，但该版本未附独立 LICENSE 文件；本次保留原始说明，不自行补写授权文件。
