# KIKI · 个人创作档案

根据提供的两份视觉规范制作；以 V2 的黑底、蓝白悬浮拼贴、粒子聚合和物品聚焦交互为主。GSAP 技能保存在 `.agents/skills/`。

## 本地运行

Node.js 22.12+（已用 24.19.0 验证）。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5174 --strictPort
```

```sh
npm run build
npm run preview -- --port 4173
```

`dist/` 为可部署的静态网站，无后端、数据库或密钥要求。字体使用 Google Fonts，网络不可用时自动使用系统中文字体。

## 修改内容

- `src/content.js`：示例姓名、方向、联系方式、分类及案例文字。当前所有案例为演示内容，不代表真实履历。
- `src/main.js`：日志结构、物品聚焦、路由、粒子和 GSAP 动画。
- `src/style.css`：统一颜色、布局、响应式和减少动态模式。
- `public/archive.svg`：原创档案示意插画，粒子从同一透明 SVG 采样，与 HTML 点击入口共享坐标。

项目地址使用 `#project/content`、`#project/ai`、`#project/visual`、`#project/about`。首页仅显示日志，原下方目录及联系内容收纳在日志内部。点击物品后居中转正，点击外部空白、关闭按钮、浏览器返回或 Escape 恢复原位；内部标签切换概览、过程、作品和日志目录。首次会话播放粒子开场，可跳过、重播；减少动态模式直接显示最终档案。

当前没有真实联系方式和简历文件，因此不提供虚假的邮箱或下载入口。填入真实邮箱后可通过联系窗口打开邮件。此首版未连接真实视频、作品证据及个人数据。

## 已验证

生产构建；真实 Chromium 浏览器下的粒子开场完成、四类物品聚焦、物品居中且平行屏幕、目录内收、空白退出与焦点归还、快速开关切换、Escape、手机布局和减少动态模式。网站需重新部署到 Netlify 后线上才会更新。
